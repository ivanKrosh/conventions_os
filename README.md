# Домовленості програмування для ОС — демонстрації

Демонстраційні програми до заняття 4 курсу «Системне програмування»
(ВСП «Фаховий коледж інформаційних систем і технологій КНЕУ ім. Вадима Гетьмана»).

Тема заняття — **домовленості, за якими прикладна програма взаємодіє з Windows API**: те, чого не перевіряє компілятор, але без чого програма працює неправильно.

## Склад рішення

Рішення `Demo_Lecture_4.slnx`, шість проєктів — по одному на кожну домовленість.

| Проєкт | Файл | Що показує |
|---|---|---|
| `Demo0_types` | `types.c` | типи Windows як `typedef`: розміри `BYTE`…`WCHAR`; чому `BOOL` — це `int` і чому порівняння `if (result == TRUE)` є помилкою |
| `Demo1_text` | `text.c` | пара функцій A/W; `strlen` проти `wcslen` проти `sizeof` для одного й того самого рядка; вивід через `WriteConsoleW` |
| `Demo3_handlers` | `handllers.c` | дескриптор як дозвіл, який треба повернути: два режими роботи, з `CloseHandle` і без нього, з підрахунком дескрипторів процесу |
| `Demo4_error` | `error.c` | ланцюжок `перевірка результату → GetLastError → FormatMessage` і втрата коду помилки, якщо його прочитати не одразу |
| `Demo5_buffer` | `buffer.c` | двофазний виклик `GetCurrentDirectoryW`: хто виділяє буфер, що повертає функція в кожному з трьох випадків; поле `cb` структури |
| `Demo6_exit` | `exit.c` | код повернення процесу (`ERRORLEVEL`) і розділення `stdout` та `stderr` |

## Як зібрати

**Visual Studio:** відкрити `Demo_Lecture_4.slnx`, платформа x64, конфігурація Debug, зібрати рішення.

**Командний рядок** (Developer Command Prompt for VS), кожен файл окремо:

```
cl /utf-8 /W4 types.c
cl /utf-8 /W4 text.c user32.lib
cl /utf-8 /W4 handllers.c
cl /utf-8 /W4 error.c
cl /utf-8 /W4 buffer.c
cl /utf-8 /W4 exit.c
```

Прапорець `/utf-8` обов'язковий: вихідні файли збережено в UTF-8, і без нього кириличні рядки буде зіпсовано вже на етапі компіляції.

## Як запускати

```
Demo3_handlers.exe          дескриптори закриваються
Demo3_handlers.exe leak     CloseHandle навмисно пропущено
Demo1_text.exe gui          додатково показує MessageBoxW
Demo6_exit.exe 2            завершується з кодом 2
```

Після `Demo6_exit.exe` подивитися код завершення: `echo %ERRORLEVEL%`.

Якщо замість українського тексту в консолі видно нечитні символи — перемкніть кодову сторінку командою `chcp 65001`. Це і є одна з домовленостей, про які йдеться в занятті: кодування задає не програма, а середовище відображення.
